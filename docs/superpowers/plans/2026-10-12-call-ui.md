# call-ui 通话 GUI 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 media_talk_rust 加一个 `gui` 子命令: Slint 三态通话界面 (拨号/来电/通话中), Windows (winit) 和 RK3566 Armbian 无桌面 (linuxkms) 都能跑, 复用 ipcam-sip/ipcam-gst 现有 SIP+RTP 能力.

**Architecture:** Slint 事件循环占主线程; SIP 在独立 std::thread 上跑自己的 tokio runtime (注册/来电/拨号/re-INVITE); GStreamer 收发管道沿用 ipcam-gst 自管线程。GUI↔SIP 用 tokio unbounded channel (命令) + `slint::invoke_from_event_loop` (事件) 桥接。视频接收经 rtp_recv 新增的 appsink tap 拉 RGBA 帧进 Slint 纹理; 音频接收走现有 playback 链 (autoaudiosink)。

**Tech Stack:** slint 1.x (std-widgets), tokio, rsipstack (经 ipcam-sip), gstreamer (经 ipcam-gst)。

设计文档: `docs/superpowers/specs/2026-10-12-call-ui-design.md` (已批准, commit c36b2b7)。

### Task 1: rtp_recv 加视频帧 tap (appsink 出口)

GUI 不能用 autovideosink (会弹独立窗口, 无法嵌进 Slint)。给 `RtpRecvConfig` 加
`video_tap: Option<VideoFrameSink>`: 视频路的"播放分支"在 tap 存在时走

音频 playback (autoaudiosink) 不受影响。tap 优先于 autovideosink: tap=Some 时

```rust
/// GUI 视频通路: 视频帧经 appsink tap 回调吐 RGBA 裸帧 (不进 autovideosink).
/// 环回发 H264, tap 必须收到帧且宽高与源一致
#[test]
fn video_tap_receives_decoded_frames() {
    let _ = tracing_subscriber::fmt().with_test_writer().try_init();
    crate::ensure_init_internal().unwrap();

    let frames = std::sync::Arc::new(std::sync::atomic::AtomicU64::new(0));
    let dims = std::sync::Arc::new(parking_lot::Mutex::new((0u32, 0u32)));
    let tap: crate::VideoFrameSink = {
        let frames = frames.clone();
        let dims = dims.clone();
        std::sync::Arc::new(parking_lot::Mutex::new(move |f: crate::RawVideoFrame| {
            frames.fetch_add(1, std::sync::atomic::Ordering::Relaxed);
            *dims.lock() = (f.width, f.height);
            // data 长度必须够 stride*height (回调内有效)
            assert!(f.data.len() >= f.stride * f.height as usize);
        }))
    };

    let receiver = start_rtp_receiver(RtpRecvConfig {
        path: None,
        playback: true, // 音频仍走 autoaudiosink; 视频被 tap 接管
        video_tap: Some(tap),
        video: Some((42130, VideoCodec::H264)),
        audio: None,
    })
    .expect("receiver starts");

    let sender = gst::parse::launch(
        "videotestsrc is-live=true ! video/x-raw,width=320,height=240,framerate=15/1 \
         ! x264enc tune=zerolatency ! rtph264pay ! udpsink host=127.0.0.1 port=42130",
    )
    .expect("sender pipeline parses")
    .downcast::<gst::Pipeline>()
    .expect("sender is a pipeline");
    sender.set_state(gst::State::Playing).unwrap();
    std::thread::sleep(Duration::from_secs(3));

    receiver.stop();
    sender.set_state(gst::State::Null).ok();

    assert!(frames.load(std::sync::atomic::Ordering::Relaxed) > 10, "tap got no frames");
    assert_eq!(*dims.lock(), (320, 240));
}
```

新增构建函数 (播放分支的 tap 变体, 替换 autovideosink):

```rust
/// 视频 tap 分支链头之后的一段: decode → convert → capsfilter(RGBA) →
/// appsink(回调吐帧). 返回要接进 tee/链尾的元素列表已 link 完成.
/// capsfilter 锁 RGBA: tap 回调契约就是 RGBA 裸帧 (ingest::tap 同契约)
fn build_video_tap_branch(
    decode_name: &str,
    tap: &crate::VideoFrameSink,
) -> Result<Vec<gst::Element>, GstStreamError> {
    let decode = make(decode_name)?;
    let convert = make("videoconvert")?;
    let rgba = make("capsfilter")?;
    rgba.set_property(
        "caps",
        gst::Caps::builder("video/x-raw").field("format", "RGBA").build(),
    );
    let appsink = make("appsink")?;
    appsink.set_property("emit-signals", true);
    disable_sink_async(&appsink);
    let sink = appsink
        .dynamic_cast::<gstreamer_app::AppSink>()
        .map_err(|_| GstStreamError::Init("appsink cast failed".into()))?;
    let tap = tap.clone();
    sink.set_callbacks(
        gstreamer_app::AppSinkCallbacks::builder()
            .new_sample(move |appsink| {
                let sample = appsink.pull_sample().map_err(|_| gst::FlowError::Eos)?;
                let caps = sample.caps().ok_or(gst::FlowError::Error)?.clone();
                let s = caps.structure(0).ok_or(gst::FlowError::Error)?;
                let width = s.get::<i32>("width").map_err(|_| gst::FlowError::Error)? as u32;
                let height = s.get::<i32>("height").map_err(|_| gst::FlowError::Error)? as u32;
                let buffer = sample.buffer().ok_or(gst::FlowError::Error)?;
                let map = buffer.map_readable().map_err(|_| gst::FlowError::Error)?;
                // videoconvert 输出的 RGBA 是紧凑排列, 但显式按 stride 处理更安全:
                // gst 2.20+ 有 stride 元数据, 这里按紧凑算 (width*4)
                let frame = crate::RawVideoFrame {
                    width,
                    height,
                    stride: width as usize * 4,
                    data: &map,
                };
                (tap.lock())(frame);
                Ok(gst::FlowSuccess::Ok)
            })
            .build(),
    );
    Ok(vec![decode, convert, rgba, appsink])
}
```

`match (mux, playback)` 的分支条件改为按 `tap.is_some()` 分流视频播放支路:
`(None, true)` 和 `(Some, true)` 两个分支里, `tap` 为 Some 时用
`build_video_tap_branch` 的产物替换 `[decode, convert, sink(autovideosink)]`
这三件 (tee 场景替换 play 分支的三件), 其余逻辑 (leaky queue/mux/link 顺序) 不变。
注意 `(None, false)` 且 `tap.is_some()` 也要合法 (纯 tap 不收不播): 原分支报错
条件改为 `tap.is_none()` 才报错。

ipcam-gst Cargo.toml 确认 `gstreamer-app` 依赖存在 (ingest/tap 已用过同类 API;
若没有, `[dependencies]` 加 `gstreamer-app = "0.24"` — 与现有 gstreamer 版本对齐,
先看 Cargo.toml 里 gstreamer 的版本号跟着写)。

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
#[repr(i32)]
pub enum Phase {
    #[default]
    Idle = 0,
    Outgoing = 1,
    Incoming = 2,
    InCall = 3,
}

/// SIP 后台 → UI 的事件
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum UiEvent {
    Registered,
    RegisterFailed(String),
    Incoming { caller: String },
    Confirmed { peer: String },
    /// 通话结束 (对端 BYE / 本地挂断 / 对方取消), reason 进日志
    Terminated { reason: String },
    /// 呼叫/接听失败 (4xx/5xx/超时/媒体起不来)
    Failed { reason: String },
}

/// UI 决策出的动作, bridge 翻译成 SIP worker 命令
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Effect {
    Dial(String),
    Accept,
    Reject,
    Hangup,
}

#[derive(Debug, Default)]
pub struct AppState {
    pub phase: Phase,
    pub peer: String,
    pub error: String,
}

impl AppState {
    /// SIP 事件驱动状态迁移. 事件可能迟到 (比如挂断后才来 Confirmed),
    /// 与当前阶段不匹配的事件只清错误不迁移, 避免界面乱跳
    pub fn on_event(&mut self, ev: UiEvent) {
        match ev {
            UiEvent::Registered => self.error.clear(),
            UiEvent::RegisterFailed(reason) => self.error = format!("注册失败: {reason}"),
            UiEvent::Incoming { caller } => {
                // 占线时 worker 已直接拒掉, 到这里一定是 Idle
                if self.phase == Phase::Idle {
                    self.phase = Phase::Incoming;
                    self.peer = caller;
                }
            }
            UiEvent::Confirmed { peer } => {
                if matches!(self.phase, Phase::Outgoing | Phase::Incoming) {
                    self.phase = Phase::InCall;
                    self.peer = peer;
                    self.error.clear();
                }
            }
            UiEvent::Terminated { .. } | UiEvent::Failed { .. } => {
                if let UiEvent::Failed { reason } = &ev {
                    if self.phase != Phase::Idle {
                        self.error = reason.clone();
                    }
                }
                self.phase = Phase::Idle;
                self.peer.clear();
            }
        }
    }

    /// 拨打: 仅 Idle 且号码非空; 返回 Effect 给 bridge 转发 worker
    pub fn dial(&mut self, number: String) -> Option<Effect> {
        let number = number.trim().to_string();
        if self.phase != Phase::Idle || number.is_empty() {
            return None;
        }
        self.phase = Phase::Outgoing;
        self.peer = number.clone();
        self.error.clear();
        Some(Effect::Dial(number))
    }

    /// 接听: 仅 Incoming
    pub fn accept(&mut self) -> Option<Effect> {
        (self.phase == Phase::Incoming).then_some(Effect::Accept)
    }

    /// 拒接: 仅 Incoming, 立即回 Idle
    pub fn reject(&mut self) -> Option<Effect> {
        if self.phase != Phase::Incoming {
            return None;
        }
        self.phase = Phase::Idle;
        self.peer.clear();
        Some(Effect::Reject)
    }

    /// 挂断/取消: Outgoing 或 InCall 有效, 立即回 Idle
    /// (不等 worker 确认, 界面对讲机场景手感优先; worker 失败会再报 Failed)
    pub fn hangup(&mut self) -> Option<Effect> {
        if !matches!(self.phase, Phase::Outgoing | Phase::InCall) {
            return None;
        }
        self.phase = Phase::Idle;
        self.peer.clear();
        Some(Effect::Hangup)
    }
}
```

```rust
//! GUI↔SIP worker 桥: 命令 (UI→worker) 走 tokio unbounded channel
//! (slint 回调是同步上下文, unbounded send 不阻塞); 事件 (worker→UI)
//! 走 slint::invoke_from_event_loop 回主线程更新 AppState 和属性.

use std::cell::RefCell;
use std::rc::Rc;
use tokio::sync::mpsc::{UnboundedReceiver, UnboundedSender, unbounded_channel};

use crate::MainWindow;
use crate::app::{AppState, Phase, UiEvent};

/// UI → SIP worker 命令
#[derive(Debug)]
pub enum WorkerCmd {
    Dial(String),
    Hangup,
    Accept,
    Reject,
}

pub fn cmd_channel() -> (UnboundedSender<WorkerCmd>, UnboundedReceiver<WorkerCmd>) {
    unbounded_channel()
}

/// worker → UI 回投: 任何线程可调, 排队进 slint 事件循环
#[derive(Clone)]
pub struct UiHandle {
    weak: slint::Weak<MainWindow>,
    app: Rc<RefCell<AppState>>,
}

impl UiHandle {
    pub fn new(weak: slint::Weak<MainWindow>, app: Rc<RefCell<AppState>>) -> Self {
        Self { weak, app }
    }

    /// 投递事件: 主线程上先过状态机, 再把字段刷到 slint 属性
    pub fn post(&self, ev: UiEvent) {
        let weak = self.weak.clone();
        let app = self.app.clone();
        let _ = slint::invoke_from_event_loop(move || {
            app.borrow_mut().on_event(ev);
            if let Some(ui) = weak.upgrade() {
                let app = app.borrow();
                ui.set_phase(app.phase as i32);
                ui.set_peer(app.peer.as_str().into());
                ui.set_error_text(app.error.as_str().into());
            }
        });
    }
}
```

```rust
//! SharedPixelBuffer, invoke_from_event_loop 把 Image 刷到 UI.
//! 25fps 级别的 invoke 开销可接受, 不做帧丢弃节流 (YAGNI).

use slint::{Image, Rgba8Pixel, SharedPixelBuffer};

/// 构造视频帧 tap: 每帧拷进 slint::Image 推到 MainWindow.video_frame.
/// 回调跑在 GStreamer 流线程 — 只拷数据 + invoke, 别碰 UI 状态
pub fn make_frame_sink(ui: slint::Weak<crate::MainWindow>) -> ipcam_gst::VideoFrameSink {
    std::sync::Arc::new(parking_lot::Mutex::new(move |f: ipcam_gst::RawVideoFrame| {
        let mut buf = SharedPixelBuffer::<Rgba8Pixel>::new(f.width, f.height);
        let dst = buf.make_mut_bytes();
        let row = f.width as usize * 4;
        for y in 0..f.height as usize {
            let src = &f.data[y * f.stride..y * f.stride + row];
            dst[y * row..(y + 1) * row].copy_from_slice(src);
        }
        let img = Image::from_rgba8(buf);
        let ui = ui.clone();
        let _ = slint::invoke_from_event_loop(move || {
            if let Some(ui) = ui.upgrade() {
                ui.set_video_frame(img);
            }
        });
    }))
}
```

```rust
/// 启动通话 GUI: 主线程跑 slint 事件循环, SIP worker 在后台线程.
/// 窗口关闭后命令通道断开, worker 收到后 client.stop() 优雅退出
pub fn run(cfg: session::GuiSipConfig) -> anyhow::Result<()> {
    let ui = MainWindow::new()?;
    let app = std::rc::Rc::new(std::cell::RefCell::new(app::AppState::default()));
    let handle = bridge::UiHandle::new(ui.as_weak(), app.clone());
    let (cmd_tx, cmd_rx) = bridge::cmd_channel();
    let tap = video::make_frame_sink(ui.as_weak());
    session::spawn(cfg, cmd_rx, handle, tap);

    // 把 AppState 字段刷到 slint 属性 (UiHandle::post 里也是这段)
    fn sync_props(ui: &MainWindow, app: &app::AppState) {
        ui.set_phase(app.phase as i32);
        ui.set_peer(app.peer.as_str().into());
        ui.set_error_text(app.error.as_str().into());
    }

    // UI 回调 → 状态机决策 → Effect 翻译 worker 命令 → 刷属性
    {
        let app = app.clone();
        let cmd_tx = cmd_tx.clone();
        let weak = ui.as_weak();
        ui.on_dial(move |number| {
            let eff = app.borrow_mut().dial(number.as_str().to_string());
            if let Some(app::Effect::Dial(n)) = eff {
                let _ = cmd_tx.send(bridge::WorkerCmd::Dial(n));
            }
            if let Some(ui) = weak.upgrade() {
                sync_props(&ui, &app.borrow());
            }
        });
    }
    {
        let app = app.clone();
        let cmd_tx = cmd_tx.clone();
        let weak = ui.as_weak();
        ui.on_accept_call(move || {
            if app.borrow_mut().accept().is_some() {
                let _ = cmd_tx.send(bridge::WorkerCmd::Accept);
            }
            if let Some(ui) = weak.upgrade() {
                sync_props(&ui, &app.borrow());
            }
        });
    }
    {
        let app = app.clone();
        let cmd_tx = cmd_tx.clone();
        let weak = ui.as_weak();
        ui.on_reject_call(move || {
            if app.borrow_mut().reject().is_some() {
                let _ = cmd_tx.send(bridge::WorkerCmd::Reject);
            }
            if let Some(ui) = weak.upgrade() {
                sync_props(&ui, &app.borrow());
            }
        });
    }
    {
        let app = app.clone();
        let weak = ui.as_weak();
        ui.on_hangup(move || {
            if app.borrow_mut().hangup().is_some() {
                let _ = cmd_tx.send(bridge::WorkerCmd::Hangup);
            }
            if let Some(ui) = weak.upgrade() {
                sync_props(&ui, &app.borrow());
            }
        });
    }
    ui.run()?;
    Ok(())
}
```
